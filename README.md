# Assignment 3 - Django Polls Project

## Project Description
This is a customized Django polls project created for COMP314 Assignment 3.
It is based on the Django tutorial and includes personal modifications such as a custom homepage style and custom poll questions.

## Tools Used
- Python
- Django
- Git
- GitHub

## Setup Instructions

1. Clone the repository

git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git

2. Navigate into the project folder

cd assignment3_django

3. Create virtual environment

python -m venv venv

4. Activate environment

Windows:
venv\Scripts\activate

5. Install dependencies

pip install -r requirements.txt

6. Run migrations

python manage.py migrate

7. Run server

python manage.py runserver

8. Open in browser

http://127.0.0.1:8000/polls/
